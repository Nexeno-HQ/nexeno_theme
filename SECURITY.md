# Security Policy

## Supported Versions

| Version | Nextcloud version | Supported          |
| ------- | ----------------- | ------------------ |
| 1.0.x   | 32, 33, 34, 35    | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security issues in public GitHub issues.
Send the details to TODO-security@example.com instead, including:

- App version and Nextcloud version
- A description of the vulnerability
- Steps to reproduce

We will confirm the report, assess its impact and release a fix as soon as possible.
The vulnerability will be disclosed publicly once a fixed release is available.
