# Security Policy

## Supported Versions

| Version | Nextcloud version | Supported          |
| ------- | ----------------- | ------------------ |
| 1.2.x   | 32, 33, 34, 35, 36 (pre-release) | :white_check_mark: |
| 1.1.x   | 32, 33, 34, 35    | :x:                |
| 1.0.x   | 32, 33, 34, 35    | :x:                |

Security fixes go into the latest 1.2.x release. On 1.1.x or 1.0.x, update to the latest 1.2.x to get them.

## Reporting a Vulnerability

Please do not report security issues in public GitHub issues.
Send the details to support@nexeno.io instead, including:

- App version and Nextcloud version
- A description of the vulnerability
- Steps to reproduce

We will confirm the report, assess its impact and release a fix as soon as possible.
The vulnerability will be disclosed publicly once a fixed release is available.
